# We Read Too - DiscoveryGate Publishing

A beautiful landing page for the "We Read Too" children's book series by Dr. Amy Salter.

## Pages

- **Homepage** (`/`) — Full landing page with hero, books, bundles, about, events, and contact sections

## Tech Stack

- React 18 + Vite
- Tailwind CSS + shadcn/ui
- Fraunces (headings) + Nunito Sans (body) fonts
- Warm cream/teal/coral color palette

## Components

All landing page components live in `webapp/src/components/landing/`:
- `Navbar` — Fixed navigation with smooth scroll
- `HeroSection` — Main hero with headline and CTAs
- `BrandBridge` — DiscoveryGate Publishing mission
- `BooksSection` — Three book cards with add-to-cart
- `BundlesSection` — Bundle pricing tiers
- `AboutSection` — Dr. Amy Salter bio with photo
- `EventsSection` — Upcoming events list
- `HowItWorks` — 3-step reading journey
- `Testimonial` — Customer quote
- `ShopCTA` — Call-to-action banner
- `EmailSignup` — Newsletter signup form
- `Footer` — Brand info and contact
